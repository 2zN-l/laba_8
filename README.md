# Змейка
## Название приложения 
**Snake Game** - игра "Змейка".

<br>
## Описание игры
В данной игре нужно управлять змейкой, которая движется по полю и собирает еду. С каждым съеденым кусочком змейка становится длиннее (на одну клеточку).
Счёт считается с каждым съеденым кусочком - 1 кусочек = 10 очков.
Игра заканчивается, если змейка врезается в собственное тело.
Управление осуществляется стрелками. Рекорд сохраняется.

## Инструкция по запуску

1. Устанавливаем библиотеку PyGame (pip install pygame)
2. Запустить игру (python3 main.py)

## Краткая справка работы программы
1. Файл __init__.py
Импортирует все классы из пакета. Делает папку snake_game полноценным пакетом.

2. exceptions.py
Классы собственных исключений. Определяет пользовательсике исключения для обработки ошибок в игре.

3. skane.py
Управляет змейкой. Хранит все данные о змейке (позиция, направление, длина) и управляет её поведением

4. food.py
Управляет едой. Хранит позицию еды и управляет её появлением

5. game.py
Основная логика игры. Объединяет змейку, еду, управление и игровой цикл в одно целое.

6. main.py
Точка входа в программу. Запускает игру.
